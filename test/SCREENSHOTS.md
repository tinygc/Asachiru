# アプリケーションスクリーンショット

## 概要

AsaChil (朝チル) アプリケーションの各画面のスクリーンショット説明です。

実際のスクリーンショットは実機テスト時に取得予定です。

---

## 1. SplashActivity（スプラッシュ画面）

### 画面説明
- **目的**: アプリ起動時の初期画面、設定チェック
- **表示時間**: 瞬時（設定チェック後すぐに遷移）
- **背景色**: 黒 (#000000)
- **表示要素**: なし（設定チェックのみ実行）

### 画面遷移
- 設定なし → SetupActivity
- 設定あり → MainActivity

### スクリーンショット想定
```
┌─────────────────────────────┐
│                             │
│                             │
│                             │
│        [黒い背景]            │
│      （すぐに遷移）          │
│                             │
│                             │
│                             │
└─────────────────────────────┘
```

---

## 2. SetupActivity（初回設定画面）

### 画面説明
- **背景色**: 黒 (#000000)
- **テキスト色**: 白 (#FFFFFF)
- **フォントサイズ**: 大きめ（TV向け）

### 表示要素

#### タイトル
- **テキスト**: "初回設定"
- **サイズ**: 48sp
- **スタイル**: Bold
- **配置**: 画面上部中央

#### 郵便番号入力エリア
- **ラベル**: "郵便番号（7桁）"
- **サイズ**: 32sp
- **入力フィールド**:
  - 背景色: #333333
  - サイズ: 400dp × 80dp
  - ヒント: "例: 1000001"
  - 入力タイプ: 数字のみ
  - 最大文字数: 7桁

#### ニュース読み上げ間隔設定
- **ラベル**: "ニュース読み上げ間隔"
- **サイズ**: 32sp
- **現在値表示**: "30 分" (デフォルト)
- **スライダー**:
  - 最小値: 1
  - 最大値: 60
  - デフォルト: 30
  - 幅: 600dp

#### 保存ボタン
- **テキスト**: "保存"
- **サイズ**: 300dp × 80dp
- **背景色**: #4CAF50（緑）
- **テキストサイズ**: 32sp
- **配置**: 画面下部中央

### スクリーンショット想定
```
┌─────────────────────────────┐
│                             │
│       初回設定              │
│                             │
│   郵便番号（7桁）            │
│  ┌───────────────┐          │
│  │   1000001    │          │
│  └───────────────┘          │
│                             │
│ ニュース読み上げ間隔         │
│       30 分                 │
│  ├─────●─────────┤          │
│  1              60          │
│                             │
│    ┌─────────┐              │
│    │  保存   │              │
│    └─────────┘              │
└─────────────────────────────┘
```

## 3. MainActivity（メイン画面）

### 画面説明
- **背景**: 黒 (#000000) + ビジュアライザー（25%透過）
- **レイアウト**: ConstraintLayout
- **全画面表示**: ステータスバー非表示

### 表示要素（レイヤー構成）

#### 背景レイヤー: VisualizerView
- **サイズ**: 全画面
- **バー数**: 50本
- **カラー**: パステルレインボー（8色循環）
- **不透明度**: 25%
- **フレームレート**: 30fps制限
- **アニメーション**: 音楽の波形に連動

#### 左上: ClockView
- **時刻表示**:
  - フォントサイズ: 96sp
  - カラー: 白 (#FFFFFF)
  - フォーマット: "HH:mm"
- **日付表示**:
  - フォントサイズ: 48sp
  - カラー: 曜日によって変化
    - 日曜日: 赤 (#FF0000)
    - 土曜日: 青 (#0000FF)
    - 平日: 黒 (#000000)
  - フォーマット: "yyyy-MM-dd (曜日)"
- **更新間隔**: 1秒

#### 右上: WeatherView
- **天気アイコン**:
  - サイズ: 80sp
  - 種類: ☀（晴れ）、☁（曇り）、☂（雨）、⛄（雪）
- **気温表示**:
  - フォントサイズ: 64sp
  - カラー: 白 (#FFFFFF)
  - フォーマット: "XX°C"
- **降水確率**:
  - フォントサイズ: 32sp
  - カラー: 白 (#FFFFFF)
  - フォーマット: "降水確率 XX%"
- **更新間隔**: 30分

#### 下部: NewsView
- **ニュースタイトル**:
  - フォントサイズ: 36sp
  - カラー: 白 (#FFFFFF)
  - アイコン: 📰
  - フォーマット: "📰 [ニュースタイトル]"
- **表示位置**: 画面下部、全幅
- **更新間隔**: 設定による（1～60分）
- **読み上げ**: TTS（日本語）

- サイズ: 24sp～32sp
