This directory should contain Lo-Fi music files for the application.

## Required Files

Please place the following audio files in this directory:

1. `lofi_01.mp3` - Chill Morning (approximately 3 minutes)

## File Format

- Format: MP3
- Quality: Medium to High (128-320 kbps recommended)
- Genre: Lo-Fi
