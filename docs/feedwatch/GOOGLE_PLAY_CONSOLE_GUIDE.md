# RSS FeedWatch - Google Play Console 登録ガイド

## 概要

このドキュメントでは、RSS FeedWatchをGoogle Play Consoleに登録し、Play Storeで公開するまでの手順を説明します。

## 事前準備

### 必要なもの

1. ✅ Google Play Developer アカウント（登録料: $25 USD、1回限り）
2. ✅ リリース用AABファイル（`app-feedwatch-release.aab`）
3. ✅ ストアリスティング素材
   - ハイレゾアイコン（512x512）: `FeedWatch_HiresoIcon.png`
   - フィーチャーグラフィック（1024x500）: `FeedWatch_FeatureGraph.png`
   - TVバナー（320x180）: `FeedWatch_TvBanner.png`
   - スクリーンショット（最低2枚）: `FeedWatch_Screenshot.png`, `FeedWatch_Screenshot2.png`
4. ✅ プライバシーポリシーURL
5. ✅ ストア説明文とメタデータ

### Google Play Developer アカウントの作成

まだアカウントをお持ちでない場合：

1. https://play.google.com/console にアクセス
2. Googleアカウントでサインイン
3. 開発者登録（$25 USD の1回限りの支払い）
4. 開発者プロフィール情報の入力

## ステップ1: 新しいアプリの作成

### 1.1 アプリの作成

1. Google Play Console にログイン: https://play.google.com/console
2. 「すべてのアプリ」→「アプリを作成」をクリック
3. 以下の情報を入力：

```
アプリ名: RSS FeedWatch
デフォルトの言語: 日本語（日本）
アプリまたはゲーム: アプリ
無料または有料: 無料
```

4. 「Play のアプリコンテンツポリシー」と「米国輸出法」に同意
5. 「アプリを作成」をクリック

### 1.2 ダッシュボード

アプリ作成後、ダッシュボードが表示されます。以下のタスクを順番に完了していきます。

## ステップ2: アプリのセットアップ

### 2.1 アプリのアクセス権

**メニュー**: ポリシー → アプリのアクセス権

1. 「すべての機能を制限なく利用できる」を選択
2. 「保存」をクリック

### 2.2 広告

**メニュー**: ポリシー → 広告

1. 「はい、アプリに広告が含まれています」を選択（AdMob使用のため）
2. 「保存」をクリック

### 2.3 コンテンツレーティング

**メニュー**: ポリシー → コンテンツレーティング

1. 「アンケートを開始」をクリック
2. メールアドレスを入力
3. カテゴリを選択: 「ユーティリティ、生産性、コミュニケーション、その他」
4. アンケートに回答（すべて「いいえ」で問題なし）
5. レーティングを確認: 「全ユーザー対象」
6. 「送信」をクリック

### 2.4 対象ユーザーと配信地域

**メニュー**: ポリシー → 対象ユーザーと配信地域

#### 対象年齢層
```
対象年齢層: 13歳以上
```

#### 配信地域
```
国と地域: 日本
```

### 2.5 ニュースアプリ

**メニュー**: ポリシー → ニュースアプリ

1. 「このアプリはニュースアプリですか？」→「はい」を選択
2. 以下の情報を入力：

```
ニュースの出典: ユーザーが選択したRSSフィード（NHK、Yahoo!ニュース、毎日新聞等）
編集方針: アプリはRSSリーダーとして動作し、コンテンツの編集や変更は行いません
```

3. 「保存」をクリック

### 2.6 プライバシーポリシー

**メニュー**: ポリシー → アプリのプライバシーポリシー

```
プライバシーポリシーURL:
https://github.com/tinygc/asachiru/blob/master/PRIVACY_POLICY.md
```

**注意**: GitHubのRawコンテンツURLではなく、通常のページURLを使用してください。

### 2.7 データの安全性

**メニュー**: ポリシー → データの安全性

1. 「データの収集と共有」セクション
   ```
   このアプリはユーザーデータを収集または共有しますか？
   → はい（広告識別子のため）
   ```

2. 収集されるデータタイプ
   ```
   - デバイスIDまたはその他のID
     - 広告識別子（Android Advertising ID）
     - 目的: 広告またはマーケティング
     - 共有: はい（Google AdMob）
   ```

3. 「保存」をクリック

## ステップ4: リリースの作成

### 4.1 国内テスト（任意、推奨）

**メニュー**: テストとリリース → 内部テスト

1. 「新しいリリースを作成」をクリック
2. 「App Bundle をアップロード」をクリック
3. `app-feedwatch-release.aab` をアップロード
4. リリース名を入力: `v1.0 (初回リリース)`
5. リリースノート（日本語）を入力:

```
🎉 RSS FeedWatch v1.0 リリース！

【初回リリース機能】
✅ RSSフィード管理（プリセット＋カスタムURL）
✅ 音声読み上げ（TTS）対応
✅ Android TV専用UI
✅ リモコン操作対応
✅ 記事詳細表示
✅ 既読スキップ機能
```

6. テスターのメールアドレスを追加（自分のアカウント等）
7. 「確認」→「公開」をクリック

### 4.2 本番環境へのリリース

内部テストが完了したら、本番環境にリリースします。

**メニュー**: テストとリリース → 製品版

1. 「新しいリリースを作成」をクリック
2. 「内部テストリリースから昇格」を選択（または再度AABをアップロード）
3. リリース名: `v1.0`
4. リリースノート（日本語）を入力
5. 「確認」をクリック

### 4.3 段階的公開（推奨）

初回リリースは段階的公開を使用することをお勧めします：

1. 「段階的公開」を選択
2. 公開率を選択: `10%`（最初は少数のユーザーに配信）
3. 問題がなければ、徐々に公開率を上げる（20% → 50% → 100%）

### 4.4 最終確認とリリース

1. すべての必須項目が完了していることを確認
2. 「製品版に公開」をクリック
3. 最終確認ダイアログで「確認」をクリック

## ステップ5: 審査と公開

### 5.1 審査プロセス

- Google Play の審査チームがアプリをレビューします
- 通常、審査には **数時間〜数日** かかります
- 審査状況はダッシュボードで確認できます

### 5.2 審査ステータス

```
審査中 → 審査完了 → 公開
```

### 5.3 公開後

アプリが承認されると、Play Storeで公開されます：

```
https://play.google.com/store/apps/details?id=com.tinygc.feedwatch
```

## トラブルシューティング

### 問題1: アプリが却下された

**原因**: ポリシー違反、技術的問題、メタデータの問題など

**解決策**:
1. 却下理由を確認
2. 問題を修正
3. 再度審査に提出

### 問題2: スクリーンショットが不適切

**原因**: サイズ、形式、内容の問題

**解決策**:
1. 推奨サイズとフォーマット（PNG/JPEG）を確認
2. TV用スクリーンショットは 16:9 のアスペクト比
3. 実際のアプリ画面を使用（モックアップ不可）

### 問題3: プライバシーポリシーにアクセスできない

**原因**: URLが無効、アクセス制限がある

**解決策**:
1. プライバシーポリシーURLが公開されていることを確認
2. ブラウザで直接アクセスできることを確認
3. GitHub Pagesや独自ドメインでホスティング
