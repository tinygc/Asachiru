### 詳細な説明（4000文字以内）
```
【RSS FeedWatchとは？】
RSS FeedWatchは、シンプルで使いやすいRSSリーダーアプリです。Android TV・スマートフォン（横画面）の両方に対応。テレビでニュースを大画面で、スマートフォンでのんびりチェック。プリセットのRSSフィード（NHK、Yahoo!ニュース等）をご用意、カスタムURLでお気に入りフィードも追加できます。

🎯 アプリの特徴
使っていないTVで、つけっぱなし推奨！
- BGM・ビジュアライザー機能（将来搭載予定）
- RSS 読み上げと詳細情報を表示
- 気になる記事はスマホでQRを読み取り、さらに詳しく

TV/スマートフォン両対応
- Android TV：リモコン操作に完全対応
- スマートフォン（横画面）：タッチ・フリック操作に最適化

✨ 主な機能

📰 RSSフィード管理
- プリセット豊富: NHK、Yahoo!ニュース、毎日新聞、ITmedia、CNET Japan 他
- カスタムURL対応: お気に入りのブログ・ニュースサイトを追加可能
- 自動更新: 1～60分の間隔で自動的に記事を取得
- 既読スキップ: 1時間内での既読記事は自動的にスキップ

📢 音声読み上げ（TTS）機能
- Android標準TTS使用: 自然な音声で記事を読み上げ
- 視覚的フィードバック: 読み上げ開始時に表示

🎮 直感的な操作方法

Android TV リモコン対応:
- ⬆️ 上キー：前の記事へ
- ⬇️ 下キー：次の記事へ
- ⬅️➡️ 左右キー：TTS ON/OFF 切り替え
- ⭕ 決定キー短押し：記事詳細表示
- ⭕ 決定キー長押し：設定画面へ
- ⏪ 戻るキー：詳細表示を閉じる

スマートフォン（横画面）:
- 👆 上フリック：前の記事へ
- 👇 下フリック：次の記事へ
- 👈 左フリック：TTS ON/OFF 切り替え
- 🖱️ タップ：記事詳細表示
- ⚙️ 設定ボタン：設定画面へ

⚙️ カスタマイズ設定
- RSSフィード選択: プリセット豊富＋カスタムURL対応
- TTS 音声読み上げ: ON/OFF を選択

🎯 こんな方におすすめ

✅ テレビを黒い飾りにしている時間が多い方
✅ テレビでニュースを大画面で見たい方
✅ 朝の準備中に最新情報をながらで聴きしたい方
✅ シンプルで軽快なRSSリーダーを探している方

📱 対応デバイス
 - 📺 Android TV
- リモコン操作（上下左右キー、決定キー）に完全対応
- Leanback UI で最適化された画面表示
- Android TV搭載テレビ、Android TV Box、Fire TV（Android TV互換モード）

🛡️ プライバシー・セキュリティ
- インターネット接続: RSSフィード取得用のみ
- その他の権限: 不要

✅ すべての設定がデバイス内にローカル保存
✅ 個人情報を外部サーバーに送信しない
✅ 最小限の権限のみ使用
✅ 詳細はプライバシーポリシーをご確認ください

本アプリは Google AdMob を使用して広告を表示しています。

📚 対応RSSフォーマット
- RSS 2.0
- RSS 1.0（RDF）
- Atom 1.0
```
