# RSS FeedWatch - Play Storeストア情報

## アプリ名
RSS FeedWatch

## 短い説明（80文字以内）
RSSフィード読み上げ専用のAndroid TVアプリ。ニュース、天気、時計を一画面で。

## 詳細説明（4000文字以内）

📡 RSS FeedWatchは、RSSフィード読み上げに特化したAndroid TV向けアプリです。

朝の支度中や料理中など、画面を見られない時でも、最新のニュースや情報を音声で聞くことができます。シンプルで使いやすいインターフェースと、高品質な音声読み上げ機能で、快適な情報収集をサポートします。

### 主な機能

📰 **RSSフィード読み上げ**
- お気に入りのRSSフィードからニュースを自動取得
- 高品質なTTS（Text-to-Speech）による音声読み上げ
- プリセットされた主要ニュースサイトから選択可能
- カスタムRSS URLにも対応
- 記事詳細ポップアップで内容確認、QRコードから記事URLへアクセス

🌤️ **天気予報表示**
- 郵便番号を入力するだけで地域の天気を自動表示
- 今日・明日の天気予報
- 気温、降水確率、天気アイコン表示

🕐 **デジタル時計**
- 見やすい大きな時計表示
- 日付と曜日も表示

🎮 **リモコン操作対応**
- Android TVリモコンで簡単操作
- 上下キーでニュース記事の切り替え
- 左右キーでTTS ON/OFF切り替え
- 決定キー短押しで詳細表示
- 決定キー長押しで設定画面へ

### 特徴

✨ **シンプルで使いやすい**
複雑な設定は不要。初回起動時に郵便番号とRSSフィードを設定するだけで、すぐに使い始められます。

🔊 **高品質な音声読み上げ**
Android標準のTTSエンジンを使用した、自然で聞きやすい音声読み上げ。

### 使い方

1. アプリを起動すると、初回設定画面が表示されます
2. 郵便番号（7桁）を入力
3. RSSフィード配信元を選択（または、カスタムURLを入力）
4. TTS（読み上げ）のON/OFFを選択
5. 「保存して開始」をタップ
6. メイン画面で自動的にニュースが読み上げられます

### リモコン操作

- **上下キー**: 前/次のニュース記事へ移動
- **左右キー**: TTS ON/OFF切り替え
- **決定キー短押し**: ニュース詳細の表示/非表示
- **決定キー長押し**: 設定画面へ移動
- **戻るキー**: 詳細表示を閉じる
