# 要件定義書

## 1. プロジェクト概要

### 1.1 プロジェクト名
**朝チル** (AsaChil)

### 1.2 目的
朝の時間につけっぱなしにする用途で、時計・天気・ニュース読み上げをチルい音楽とともに提供するAndroid TVアプリケーションを開発する。

### 1.3 ターゲットユーザー
- 朝の準備時間に情報を受動的に取得したいユーザー
- リラックスした雰囲気で情報を得たいユーザー

### 1.4 利用シーン
- 朝の身支度をしながら
- 朝食を取りながら
- 朝のルーティン中

---

## 2. 機能要件

### 2.1 時計機能

#### 2.1.1 基本仕様
- **表示形式**: デジタル時計
- **時刻表示**: 24時間表示（HH:MM形式、秒は非表示）
- **日付表示**: MM/DD形式
- **曜日表示**: 3文字の英語表記（例: Mon, Tue, Wed）をカッコ付きで表示（例: (Mon)）

#### 2.1.2 表示ルール
- **曜日の色分け**:
  - 平日（月～金）: 黒
  - 土曜: 青
  - 日曜: 赤

#### 2.1.3 配置
- 画面左上

#### 2.1.4 将来拡張
- アナログ時計表示の選択機能

---

### 2.2 天気機能

#### 2.2.1 基本仕様
- **位置情報取得**: 郵便番号（7桁、ハイフンなし）による設定
- **天気API**: 天気予報API（livedoor天気互換）を使用

#### 2.2.2 表示項目
- 天気アイコン（晴れ、曇り、雨など）
- 現在気温
- 最高気温
- 最低気温
- 降水確率

#### 2.2.3 更新タイミング
- アプリがForegroundになったとき
- 30分経過時

#### 2.2.4 配置
- 画面右側

#### 2.2.5 エラー処理
- API接続エラー時: 該当箇所にエラーメッセージを表示
- 他の機能は正常動作を継続

---

### 2.3 ニュース読み上げ機能

#### 2.3.1 基本仕様
- **ニュースソース**: NHKニュースRSS
- **音声エンジン**: Android標準TTS（Text-to-Speech）
- **読み上げ件数**: 最新10件

#### 2.3.2 読み上げタイミング
- アプリ起動10秒後から最新10件を読み上げ開始
- その後はユーザー設定の間隔で定期的に最新10件を読み上げ

#### 2.3.3 読み上げ間隔設定
- **デフォルト値**: 30分
- **設定可能範囲**: 1分～60分
- **設定タイミング**: 初回起動時
- **設定の保存**: アプリ再起動後も設定を保持

#### 2.3.4 表示
- 読み上げ中のニュースタイトルを画面左下に表示

#### 2.3.5 エラー処理
- RSS取得エラー時: 該当箇所にエラーメッセージを表示
- 他の機能は正常動作を継続

---

### 2.4 音楽再生機能

#### 2.4.1 基本仕様
- **ジャンル**: Lo-Fi
- **音源**: フリー音源をアプリに組み込み
- **曲数**: 初期バージョンで3曲

#### 2.4.2 再生方式
- **再生モード**: ループ再生
- **クロスフェード**: 3秒間のクロスフェードで曲を繋ぐ

#### 2.4.3 音量調整
- アプリ側では音量調整機能を提供しない
- TV本体の主音量で調整

#### 2.4.4 表示
- 再生中の曲名を画面左下に表示

---

### 2.5 ビジュアライザー機能

#### 2.5.1 基本仕様
- **タイプ**: スペクトラムアナライザー（縦のバータイプ）
- **動作**: 再生中の音楽に反応してリアルタイムに表示
- **デザインイメージ**: 昔のステレオデッキ風、パステルカラーでカラフルに

#### 2.5.2 詳細仕様
- **バー本数**: 50本
- **配置**: 画面全体の下部に均等配置
- **バーの幅**: 16px
- **バーの間隔**: 6px
- **配色**: パステルレインボーカラー（8色を循環）
  - #FF6B9D（パステルピンク）
  - #FFA07A（パステルオレンジ）
  - #FFD93D（パステルイエロー）
  - #6BCF7F（パステルグリーン）
  - #4ECDC4（パステルシアン）
  - #95B8D1（パステルブルー）
  - #B8A9C9（パステルパープル）
  - #F38FB1（パステルローズ）
- **アニメーション**: 0.8秒周期で上下に変化
- **高さの範囲**: 15%～85%
- **不透明度**: 25%（背景として表示）

#### 2.5.3 配置
- 画面背景にうっすら表示
- 他のUI要素の視認性を妨げないこと

---

### 2.6 初回設定機能

#### 2.6.1 設定項目
1. 郵便番号（7桁、ハイフンなし）
2. ニュース読み上げ間隔（1～60分）

#### 2.6.2 設定タイミング
- アプリ初回起動時に設定画面を表示

#### 2.6.3 設定の保存
- 入力された設定値を永続化
- アプリ再起動後も設定を保持

#### 2.6.4 将来拡張
- 設定変更機能の追加

---

## 3. 非機能要件

### 3.1 画面仕様

#### 3.1.1 解像度
- **対応解像度**: 4K（3840x2160）対応
- 1080p（1920x1080）でも動作可能であること

#### 3.1.2 画面レイアウト
```
+------------------------------------------+
|  時計                       天気         |
|  (左上)                    (右側)       |
|                                          |
|                                          |
|           ビジュアライザー               |
|           (背景全体)                     |
|                                          |
|  曲名                                    |
|  ニュースタイトル                        |
|  (左下)                                  |
+------------------------------------------+
```

#### 3.1.3 UIデザイン仕様

##### 3.1.3.1 デザインコンセプト
- **テーマ**: パステルカラーでカラフルなピクセルアート風デザイン
- **雰囲気**: Chill Pulseのような癒し系・リラックス感のある空間
- **最小限の素材**: コードで生成可能なアニメーションを活用し、必要な画像素材を最小化

##### 3.1.3.2 配色
- **背景グラデーション**: パステルカラーのグラデーション（ピンク、ブルー、イエロー、パープル系）
- **時間経過による色変化**: 背景グラデーションがゆっくりと変化（20秒周期）
- **ビジュアライザー**: パステルレインボーカラー（8色のパステルカラーを循環）
- **UI要素**: 半透明の白背景（ガラスモーフィズム）

##### 3.1.3.3 フォント
- **スタイル**: ピクセルフォント風
- **使用フォント**: Press Start 2P（Google Fonts）またはピクセル系フリーフォント
- **時計サイズ**: 80px（大きく見やすく）
- **日付サイズ**: 32px
- **その他テキスト**: 20-24px程度

##### 3.1.3.4 アニメーション要素（コードで生成）

**背景アニメーション**:
- グラデーションの色変化（20秒周期でループ）
- ドットパターンオーバーレイ（静的）

**パーティクルアニメーション**:
- パステルカラーの円形パーティクルが画面内をふわふわ浮遊
- 約20個のパーティクル
- サイズ: 10-40px（ランダム）
- 移動速度: 10-20秒周期（ランダム）

**ビジュアライザー**:
- 縦型バー（50本）
- 画面全体の下部に配置
- 各バーが音楽に反応して上下に動く（0.8秒周期）
- 高さ: 15%～85%の範囲で変化
- 不透明度: 25%

**UI要素のアニメーション**:
- 時計の影が色変化（3秒周期）
- 天気アイコンのバウンス（2秒周期）
- ニュースタイトルのフェードイン（1秒）

##### 3.1.3.5 必要な画像素材（最小限）

**必須素材**:
- ピクセルフォント: 1ファイル（無料フォント使用）
- 天気アイコン: 5種類程度（晴れ、曇り、雨、雪、その他）
  - サイズ: 16x16ピクセル程度
  - ピクセルアート風

**オプション素材**:
- 背景ドットパターン: 1ファイル（コードで代用可能）

##### 3.1.3.6 UIモックアップ
- モックアップファイル: `requirement/ui_mockup_pastel.html`
- ブラウザで動作確認可能なHTML/CSS/JSで実装

### 3.2 操作方式
- **リモコン操作**: なし
- つけっぱなし用途のため、基本的に操作不要

### 3.3 パフォーマンス
- アプリ起動時間: 10秒以内
- UI応答性: スムーズな表示更新

### 3.4 対応環境
- **プラットフォーム**: Android TV
- **開発環境**: Windows 11 PowerShell

## 4. 外部連携仕様

### 4.1 天気情報API
- **API名**: 天気予報API（livedoor天気互換）
- **認証**: 不要
- **取得情報**: 天気予報、気温、降水確率

### 4.2 ニュースRSS
- **ソース**: NHKニュースRSS
- **フォーマット**: RSS/XML
- **取得情報**: ニュース見出し、本文

### 4.3 郵便番号→地域コード変換
- 郵便番号から天気APIで使用する地域コードへの変換機能が必要

---

## 5. データ仕様

### 5.1 設定データ
- 郵便番号（7桁の数値文字列）
- ニュース読み上げ間隔（1～60の整数値、単位: 分）

### 5.2 キャッシュデータ
- 天気情報（最終取得時刻、天気データ）
- ニュース情報（最終取得時刻、ニュースリスト）

---

## 6. エラー処理

### 6.1 ネットワークエラー
- 天気API接続エラー: 天気表示エリアにエラーメッセージを表示
- ニュースRSS取得エラー: ニュース表示エリアにエラーメッセージを表示
- 他の機能は影響を受けず正常動作を継続

### 6.2 入力エラー
- 郵便番号入力エラー: 入力画面でエラーメッセージを表示し、再入力を促す
- ニュース読み上げ間隔入力エラー: 入力画面でエラーメッセージを表示し、再入力を促す

---

## 7. 制約事項

### 7.1 現バージョンでの制約
- 設定変更は初回起動時のみ（設定変更機能は将来実装）
- 祝日の色分け機能は未実装（土曜・日曜のみ色分け）
- リモコンでの操作機能なし

### 7.2 技術的制約
- Android TVデバイスはGPS非搭載のため、位置情報は郵便番号で設定
- フリー音源の曲長は音源に依存
